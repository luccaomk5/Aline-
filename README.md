# Aline - Projeto Web

## 📝 Descrição

Aline é um projeto web moderno e responsivo desenvolvido com HTML, CSS e JavaScript. Este projeto inclui uma página inicial profissional com navegação, seções de informações e um formulário de contato.

## 🎨 Recursos

- ✅ Design responsivo (mobile-friendly)
- ✅ Navegação suave com scroll
- ✅ Formulário de contato interativo
- ✅ Paleta de cores moderna
- ✅ Estrutura limpa e bem organizada

## 📁 Estrutura do Projeto

```
Aline-/
├── index.html      # Página principal
├── style.css       # Estilos CSS
├── script.js       # Scripts JavaScript
└── README.md       # Este arquivo
```

## 🚀 Como Usar

1. Clone o repositório:
   ```bash
   git clone https://github.com/luccaomk5/Aline-.git
   ```

2. Abra o arquivo `index.html` no seu navegador favorito.

3. Explore o projeto e aproveite!

## 💻 Seções

- **Home**: Seção inicial com chamada para ação
- **Sobre**: Informações sobre o projeto
- **Contato**: Formulário para entrar em contato

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)
